## 🚀 Empezar Ahora

### Paso 1: Subir Archivos al Servidor

Ejecuta el script para subir los archivos mejorados.

### Paso 2: Configurar API Key

1. Ve a: https://makersuite.google.com/app/apikey
2. Crea una API key gratuita
3. Cópiala y guárdala

### Paso 3: Configurar en Dashboard

1. Abre: https://dashboard.checkin24hs.com
2. Ve a: **Flor IA** → Pestaña **"🤖 IA"**
3. Marca: **"Habilitar respuestas con IA"**
4. Selecciona: **"Google Gemini"**
5. Pega tu API Key
6. Modelo: `gemini-2.5-flash`
7. Guarda

## 📝 Checklist de Base de Conocimiento

Para cada hotel, completa:

- [ ] **Descripción detallada** (2-3 párrafos educativos)
- [ ] **Servicios e instalaciones** (con explicación de beneficios)
- [ ] **Excursiones y actividades** (qué hacer y por qué es especial)
- [ ] **Información de precios** (cómo funcionan las tarifas)
- [ ] **Políticas** (condiciones explicadas claramente)
- [ ] **Cómo llegar** (instrucciones detalladas)
- [ ] **Tips y consejos** (información práctica)
