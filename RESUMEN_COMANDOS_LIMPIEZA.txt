📋 COMANDOS SSH (Ejecutar en el servidor)

1. Ver todos los servicios:
   docker service ls

2. Ver puertos en uso:
   sudo netstat -tuln | grep -E ':(300[0-9]|301[0-9]|302[0-9])' | sort

3. Eliminar servicio específico:
   docker service rm NOMBRE_SERVICIO

4. Ver IP del servidor:
   curl ifconfig.me

5. Ver logs de un servicio:
   docker service logs NOMBRE_SERVICIO --tail 50

6. Ver estado de un servicio:
   docker service ps NOMBRE_SERVICIO
