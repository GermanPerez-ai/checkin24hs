# 📍 Guía Visual: Configurar API Key en el Dashboard

## 🎯 Ubicación Exacta

Estás en el lugar correcto:
- ✅ **Sección:** Flor IA (menú lateral izquierdo)
- ✅ **Pestaña:** IA (robot head icon)
- ✅ **Checkbox:** "Habilitar respuestas con IA" (ya está marcado)

---

## 📋 Pasos Detallados

### Paso 1: Desplázate hacia abajo en la tarjeta

En la tarjeta blanca "Configuración de Inteligencia Artificial", debajo del checkbox que ya está marcado, deberías ver:

1. **Campo "Proveedor" o "Provider"**
   - Un dropdown o selector
   - Opciones como: "OpenAI", "Google Gemini", etc.

2. **Campo "API Key"**
   - Un campo de texto donde pegarás tu clave

3. **Campo "Modelo" o "Model"**
   - Otro dropdown para seleccionar el modelo

4. **Botón "Guardar" o "Save"**

---

### Paso 2: Si NO ves estos campos

**Opción A:** Haz scroll hacia abajo en la página
- Los campos pueden estar más abajo

**Opción B:** Haz clic en el checkbox "Habilitar respuestas con IA"
- A veces los campos aparecen solo cuando está marcado
- Vuelve a marcarlo si se desmarcó

**Opción C:** Refresca la página
- Presiona `F5` o `Ctrl + R`
- A veces los campos se cargan después

---

### Paso 3: Configurar los campos

Una vez que veas los campos:

1. **Selecciona el Proveedor:**
   - Haz clic en el dropdown "Proveedor"
   - Selecciona: **"Google Gemini"** o **"Gemini"**

2. **Pega tu API Key:**
   - Ve a: https://makersuite.google.com/app/apikey
   - Crea o copia tu API Key (empieza con `AIza...`)
   - Péga la en el campo "API Key"

3. **Selecciona el Modelo:**
   - Haz clic en el dropdown "Modelo"
   - Selecciona: **"gemini-2.5-flash"** o **"gemini-2.0-flash"**

4. **Guarda:**
   - Haz clic en el botón **"Guardar"** o **"Save"**

5. **Prueba la Conexión:**
   - Busca un botón **"Probar Conexión"** o **"Test Connection"**
   - Haz clic para verificar que la API Key funciona

## 🆘 Si No Encuentras los Campos

### Opción 1: Captura de Pantalla Completa
- Haz una captura de pantalla completa de toda la tarjeta
- Puede que los campos estén más abajo

### Opción 2: Inspeccionar la Página
- Presiona `F12` para abrir las herramientas de desarrollador
- Esto puede ayudar a ver si hay campos ocultos

### Opción 3: Verificar Versión del Dashboard
- Los campos pueden estar en una versión diferente
- Verifica que tengas la última versión del dashboard
