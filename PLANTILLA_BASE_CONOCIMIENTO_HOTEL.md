## 🎯 Criterios de Calidad

Una buena base de conocimiento debe:

✅ **Educar**: Explica el "por qué", no solo el "qué"
✅ **Contextualizar**: Ayuda al cliente a entender cuándo es útil
✅ **Comparar**: Menciona diferencias con otras opciones cuando es relevante
✅ **Anticipar**: Responde preguntas que el cliente probablemente hará después
✅ **Ser práctica**: Incluye información útil para planificar
